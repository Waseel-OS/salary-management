DATABASE DESIGN & SCHEMA ARCHITECTURE

Relational Database Schema, Tables, Constraints & Foreign Key Integrity | Database: employee_salary_management

• MySQL / Local Storage Engine Active
Database: employee_salary_management | Tables: employees, salary, payslips, admin | Strict 3NF Relational Model

1. employees Table (Core Employee Master Record)

Column NameData TypeConstraint / KeyDefaultDescription
employee_idVARCHAR(20)PRIMARY KEYNoneUnique alphanumeric employee identifier (e.g. EMP001)
first_nameVARCHAR(50)NOT NULLNoneEmployee given name
last_nameVARCHAR(50)NOT NULLNoneEmployee surname
genderVARCHAR(10)NOT NULLNoneGender (Male, Female, Other)
dobDATENOT NULLNoneDate of birth (YYYY-MM-DD)
emailVARCHAR(100)UNIQUE, NOT NULLNoneOfficial employee email address
phoneVARCHAR(20)NOT NULLNone10-digit mobile number
departmentVARCHAR(50)NOT NULLNoneDepartment (IT, HR, Finance, Marketing, Operations)
designationVARCHAR(50)NOT NULLNoneOfficial job designation
joining_dateDATENOT NULLNoneCompany appointment date
basic_salaryDECIMAL(12,2)NOT NULL0.00Base wage per month in INR
bank_accountVARCHAR(30)NOT NULLNoneBank account number for salary credit
pan_numberVARCHAR(20)NOT NULLNonePAN number for tax compliance
statusVARCHAR(20)None'Active'Employment status (Active, Inactive, On Leave)

2. salary Table (Monthly Payroll Calculations)

Column NameData TypeConstraint / KeyDefaultFormula / Description
salary_idINTPRIMARY KEY, AUTO_INCREMENTNoneUnique salary record ID
employee_idVARCHAR(20)FOREIGN KEY → employeesNoneReferences employees(employee_id) ON DELETE CASCADE
salary_monthVARCHAR(20)NOT NULLNoneBilling month (e.g. September)
salary_yearINTNOT NULLNoneBilling year (e.g. 2026)
basic_salaryDECIMAL(12,2)NOT NULL0.00Base salary component
hraDECIMAL(12,2)None0.00House Rent Allowance (40% of Basic)
daDECIMAL(12,2)None0.00Dearness Allowance (10% of Basic)
allowancesDECIMAL(12,2)None0.00Special / travel / medical allowances
bonusDECIMAL(12,2)None0.00Performance bonus or incentive
pfDECIMAL(12,2)None0.00Provident Fund deduction (12% of Basic)
professional_taxDECIMAL(12,2)None0.00Professional Tax (standard ₹200)
other_deductionsDECIMAL(12,2)None0.00Loss of pay or advance recoveries
gross_salaryDECIMAL(12,2)NOT NULL0.00Gross = Basic + HRA + DA + Allowances + Bonus
total_deductionsDECIMAL(12,2)NOT NULL0.00Deductions = PF + Prof Tax + Other Deductions
net_salaryDECIMAL(12,2)NOT NULL0.00Net = Gross - Total Deductions
processed_dateDATENoneCURRENT_DATEPayroll processing timestamp

Column NameData TypeConstraint / KeyDefaultDescription

generated_dateTIMESTAMPNoneCURRENT_TIMESTAMPDate and time of official slip issue
statusVARCHAR(20)None'Generated'Slip status ('Generated', 'Issued', 'Paid')
